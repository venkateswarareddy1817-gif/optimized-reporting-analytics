# E-commerce Analytics SQL Project

## Project Overview

This project analyzes e-commerce data using MySQL.

The goal is to generate business insights such as revenue, top-selling products, customer behavior, and monthly performance.

## Technologies

- MySQL
- SQL
- MySQL Workbench
- Git
- GitHub

## Dataset

The project contains:

- Customers
- Products
- Categories
- Orders
- Order Items

## Business Analysis

The project covers:

1. Revenue by city
2. Revenue by category
3. Top-selling products
4. Monthly revenue
5. Top customers
6. Customer and order analysis
7. Final business KPIs

## SQL Concepts Used

- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- CTEs
- Window Functions
- Indexes
- EXPLAIN
- ANALYZE
- Reporting Views

## Key Business Metrics

The final analysis calculates:

- Total Orders
- Total Customers
- Total Items Sold
- Total Revenue
- Average Item Revenue
